\# System Blueprint: Custom AI Autonomous Personal Assistant



A lightweight, \*\*100% free-forever\*\* autonomous AI agent that runs 24/7 on a persistent cloud server. It integrates directly with Google services, leverages advanced AI reasoning, and communicates exclusively through a secure, native Telegram interface with dual-daily proactive voice note reports.



\---



\## 📑 1. Core Feature Specification ("What it will do")



\### 🎙️ Automated Voice Briefings (Morning \& Evening)

\*   \*\*The Morning Report (Triggered via Cloud Cron at 07:30 AM):\*\*

&#x20;   \*   Logs into your Gmail to filter and summarize high-priority or unread emails.

&#x20;   \*   Scrapes Google Classroom to extract active assignments, deadlines, and announcements.

&#x20;   \*   Fetches your Google Calendar agenda and Google Tasks to-do list for the day.

&#x20;   \*   Feeds this raw text data to the Gemini AI to draft a personal, concise, radio-style morning script.

&#x20;   \*   Converts the script into an audio file via a free text-to-speech engine and sends it directly to your Telegram chat as a playable voice note.

\*   \*\*The Evening Report (Triggered via Cloud Cron at 09:00 PM):\*\*

&#x20;   \*   Scans your calendar to review what was cleared.

&#x20;   \*   Checks Google Classroom for upcoming deadlines due tomorrow or later in the week.

&#x20;   \*   Compiles a wind-down status report detailing pending tasks.

&#x20;   \*   Converts the report to an audio file and drops the evening voice note into your Telegram chat.



\### 📅 Direct Google Workspace Control via Text

\*   \*\*Natural Language Calendar Scheduling:\*\* Texting your bot \*"Hey, book a study session with Arjun this Wednesday from 4 to 6 PM"\* instructs the AI to calculate the exact calendar timestamp, verify it against the current date, and execute a direct write request to Google Calendar.

\*   \*\*Task \& Reminders Pipeline:\*\* Sending instructions like \*"Remind me to submit my lab files by Friday midnight"\* parses the text into a task item. The background server tracks this item and forcefully pings your Telegram app when the deadline approaches.



\### 🔍 Smart Filtering \& Fetching

\*   \*\*Gmail Summarization:\*\* Periodically reads your inbox metadata, skipping marketing spam and newsletters to pull only actionable emails from professors, peers, or pinned accounts.

\*   \*\*Classroom Assignment Scraper:\*\* Directly connects to your course IDs to list pending coursework, points, and close deadlines.

\## 🛠️ 2. Architectural Design ("How it works")



\### Communication Flow

1\. \*\*User Interface Interaction:\*\* User texts the \*\*Telegram App\*\* -> Text request goes to the \*\*Free Cloud Server\*\*.

2\. \*\*Audio Return Path:\*\* \*\*Free Cloud Server\*\* processes text -> Sends a generated native \*\*Audio Voice Note\*\* back to the Telegram App.

3\. \*\*Core Processing Engine:\*\* The Free Cloud Server handles logic by distributing workflows to three parallel components:

&#x20;   \* \*\*Google Gemini API:\*\* Provides Free AI Synthesis and script generation.

&#x20;   \* \*\*Google Cloud APIs:\*\* Queries Calendar, Tasks, Gmail, and Google Classroom.

&#x20;   \* \*\*Python TTS Engine:\*\* Uses Edge-TTS to convert finalized scripts into audio voice streams.



\### The Infrastructure Stack (Zero-Cost Developer Tiers)

1\. \*\*Interface Layer (Telegram Bot API):\*\* Acts as your inputs and outputs portal. Telegram offers unrestricted, permanent bot interactions completely free of charge.

2\. \*\*Logic \& Server Layer (Render / Zeabur / Hugging Face):\*\* A persistent 24/7 Linux environment running a lightweight Python loop script. It stays awake listening for incoming webhooks (your texts) and triggers time-based jobs (the morning/evening reports).

3\. \*\*Intelligence Layer (Google AI Studio - Gemini 2.5 Flash API):\*\* The conversational brain. It reads arbitrary text commands from your chat to extract structured parameters (dates, tasks), and organizes unstructured data streams (Gmail text, Classroom feeds) into cohesive voice scripts.

4\. \*\*Integration Layer (Google Cloud Console OAuth 2.0):\*\* Authorizes your personal script to query Gmail, Google Calendar, Google Tasks, and Google Classroom APIs safely using standard web tokens.

5\. \*\*Voice Generation Layer (Edge-TTS / gTTS):\*\* Python libraries that capture the text generated by the AI model and serialize it into highly fluid, organic-sounding voice notes (`.ogg` or `.mp3` format) natively recognized by the Telegram player.

\## 🔒 3. Data Flow \& Zero-Touch Security Blueprint



\*   \*\*No Middleware Intermediaries:\*\* Because we are avoiding middleman automation engines like n8n, your personal data never crosses paths with third-party software platforms. The code communicates directly and cleanly with Google and Telegram APIs.

\*   \*\*Automated Background Token Refreshing:\*\* The script initializes an automated OAuth2 token handling block. After the absolute first-time browser login approval, it saves an encrypted token footprint file (`token.json`). The script autonomously updates this file using silent background refresh loops before it expires, meaning \*\*you will never have to re-authenticate or log back in manually.\*\*

\*   \*\*Robust Error-Catching Architecture:\*\* Every connection block is wrapped in an infinite retry loop with automatic back-off parameters. If Google's API drops momentarily or the cloud server restarts unexpectedly, the engine gracefully catches the error, self-heals, and reconnects without needing human maintenance.
